Mọi file hiện là `reference-only`; MIT chỉ có thể được xem xét ở review riêng, không phê duyệt copy hiện tại.

## Thuật ngữ

**Provider** chuyển canonical model request sang API/wire cụ thể. **Credential** là API key hoặc OAuth grant/token xác thực. **OAuth** là cơ chế người dùng uỷ quyền cho ứng dụng mà không đưa mật khẩu. **Secret** là dữ liệu phải không lộ vào prompt, log, artifact hay sandbox agent. **Sandbox** là ranh giới thực thi; tool filter không phải sandbox.

## Đã xác minh: credential và ranh giới

Có code credential/OAuth như [`agent/anthropic_credentials.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/agent/anthropic_credentials.py), [`hermes_cli/auth_codex.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/hermes_cli/auth_codex.py), [`hermes_cli/auth_oauth_grants.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/hermes_cli/auth_oauth_grants.py), profile và vault-related modules. Sự tồn tại này **không** là khuyến nghị đưa raw token vào agent runtime. Các flow phụ thuộc provider, file format và điều khoản dịch vụ; phải coi là reference-only. Browser vault/terminal backend cũng gắn với local runtime Hermes.

Các lớp kiểm tra nội bộ được thấy qua [`tools/path_security.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/tools/path_security.py), [`tools/threat_patterns.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/tools/threat_patterns.py), [`agent/redact.py`](https://github.com/NousResearch/hermes-agent/blob/69fd61b0efbe2bf7f412714ed8c35e40dfddc534/agent/redact.py), approval/tool guardrail và skill guard. Đây là useful defense-in-depth, không chứng minh model bị giới hạn quyền: một policy thật phải được executor/sandbox kiểm tra ngoài model.

## Áp dụng cho BoxFox

1. Tách router/provider process khỏi sandbox agent. Agent chỉ nhận opaque credential handle và capability hẹp, không nhận raw key/OAuth refresh token.
2. Credential broker giữ secret, scope theo user/org/provider/model, TTL, revoke và audit. Luồng API key do user/org cung cấp tách với OAuth connection người dùng cho phép.
3. Router normalise request/tool stream, redacts observability; policy chọn provider/model/fallback nhưng không để agent tự đổi quyền credential.
4. Approval có policy server-side; terminal/browser/file/network phải chạy trong sandbox thực và giới hạn mount/egress.
5. Không vendor nguyên OAuth/credential persistence Hermes, browser hoặc environments; chỉ lấy interface pattern sau threat model riêng.

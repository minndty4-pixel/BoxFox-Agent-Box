# So sánh các router tham chiếu

## Kết luận ngắn

BoxFox nên tự sở hữu **canonical request, policy, consent, credential broker, audit trace và capability contract**. Dùng CCR, LiteLLM, 9Router và OmniRoute như **bằng chứng tham khảo**; mọi file trong code-reference hiện là `reference-only`, không phải mã để copy/adapt. Một dependency LiteLLM hoặc adapter BoxFox tự viết chỉ có thể được quyết định trong hạng mục riêng sau review phiên bản, giấy phép và bảo mật; không sao chép đường OAuth, database credential hay MITM của các dự án.

## Ma trận đã kiểm chứng

| Tiêu chí | 9Router | OmniRoute | Claude Code Router | LiteLLM | Hướng BoxFox |
|---|---|---|---|---|---|
| Ingress | OpenAI/Claude/Gemini/Responses qua handler chung | OpenAI-compatible và nhiều đường relay | nhận nhiều endpoint/protocol qua gateway typed | Proxy có OpenAI-compatible endpoints; thư viện gọi provider | OpenAI Chat/Responses, Anthropic Messages, Gemini là ingress có phiên bản |
| Cấu hình client | endpoint local `/v1`, API key dashboard | endpoint local; header `X-Route-Model`; có MITM | profile/agent config áp endpoint local | `base_url` proxy hoặc SDK | adapter ghi cấu hình rõ ràng, có undo; mặc định không intercept |
| Translation | registry direct hoặc pivot qua OpenAI; xử lý tool/thinking/SSE | dùng `open-sse`, alias/combos | protocol endpoint + adapter và rewrite path/body | transformation theo provider; normalizer tool name | canonical AST + capability matrix + kiểm thử contract stream/tool |
| Route/fallback | combo fallback/round-robin/fusion; retry executor | combo/auto/circuit policy/affinity | policy engine, execution plan, credential chain, retry | nhiều strategy, cooldown, fallback groups | policy có thứ tự: allow → capability → budget/rate → health → fallback |
| Credential | API key/OAuth được lưu trong local DB | API key/OAuth/import local; có export route cần bảo vệ | credential pool, cooldown/limit, API-key auth | key/provider config, virtual key/proxy auth | vault/broker ngoài sandbox; handle ngắn hạn; scope/expiry/revoke |

## Bằng chứng chi tiết quan trọng

1. **Translation không chỉ đổi JSON.** 9Router dùng direct translator rồi mới pivot source → OpenAI → target; trước khi đổi còn gán ID tool call, sửa tool result thiếu và giữ intent thinking. Xem [`open-sse/translator/index.js`](https://github.com/decolua/9router/blob/17c4cc76877bd1755030a8414f8d0083f48dcccf/open-sse/translator/index.js). LiteLLM còn xây reverse map tên tool Anthropic để tránh va chạm khi chuẩn hoá. Xem [`transformation.py`](https://github.com/BerriAI/litellm/blob/c8114ba41ff76365e3fb065dd3c7ca387598fd98/litellm/llms/anthropic/chat/transformation.py).
2. **Fallback phải gắn credential và stream.** CCR tạo attempt theo credential, bỏ credential quá quota/cooldown và ghi lý do fallback; source là [`executor.ts`](https://github.com/musistudio/claude-code-router/blob/cbe5f7bb3b3511ac31274559f2e9f387cab6fe40/packages/core/src/gateway/upstream/executor.ts). LiteLLM giới hạn fallback, retry policy và cooldown trong [`router.py`](https://github.com/BerriAI/litellm/blob/c8114ba41ff76365e3fb065dd3c7ca387598fd98/litellm/router.py#L705-L790).
3. **Header route override vẫn phải qua policy.** OmniRoute giải thích `X-Route-Model` chỉ chọn model trước khi check allowlist per key và đồng bộ lại `body.model`; xem [`resolveRoutingModel.ts`](https://github.com/diegosouzapw/OmniRoute/blob/7cabac4985e8abcd7a34bad285698eebb924c46a/src/sse/handlers/resolveRoutingModel.ts). BoxFox không được coi header client là quyền để vượt policy.
4. **Redaction là allow/deny theo tên header, không chỉ UI masking.** CCR fail-closed với các tên chứa `token`, `secret`, `credential`, `key`, v.v.; xem [`sensitive-headers.ts`](https://github.com/musistudio/claude-code-router/blob/cbe5f7bb3b3511ac31274559f2e9f387cab6fe40/packages/core/src/observability/sensitive-headers.ts).

## Lựa chọn và điều không lấy

- **Lấy:** execution plan bất biến/traced, retry phân loại, capability-aware route, credential-pool health, local client profiles có thể hoàn tác, test translation theo protocol.
- **Không lấy:** lưu raw secret trong bảng connection mà agent/runtime có thể đọc; fallback từ đầu ra streaming đã phát nội dung; “đổi tên tool” như biện pháp bảo mật; nhận định mọi provider/subscription đều hợp lệ hoặc được phép chuyển tiếp.
- **Chưa lấy:** chặn TLS/MITM, auto-import credential từ máy, export token, browser/cookie harvesting. Các khả năng này làm tăng quyền truy cập, rủi ro điều khoản dịch vụ và bề mặt RCE/SSRF.
